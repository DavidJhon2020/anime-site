# 季刊新番 · Seasonal Anime Quarterly

> 一份按季度发刊的日本电视动画档案。全量收录，不做删选。

**在线预览**：https://davidjhon2020.github.io/anime-site/

---

## 这是什么

一本「季刊」形态的动画档案站点，收录 **2025 夏季 – 2026 秋季共 6 期、393 部**日本 TV 动画。

| 栏目 | 说明 |
| --- | --- |
| 封面 | 刊名、期号、「本日特集」封面故事与图版 |
| 01 特集 | 每日轮换一部作品，附编辑手写评语（约 33 部备选） |
| 02 放送日程 | 本周节目单（周一–周日），点选任一日查看当日放送清单 |
| 03 片单 | 三种读法：周放送时刻表 / 图版 / 索引，支持原作类型筛选与「仅看推荐」 |
| 04 过刊 | 六期文字索引，点击切期 |
| 05 奥付 | 数据来源与「号色」说明 |

其他：全局搜索（含制作公司别名，如「骨头社 → BONES」）、详情弹窗、键盘左右切期、`/` 聚焦搜索、纸本（默认）与夜间双主题（跟随本地记忆）。

## 目录结构

```
anime-site/
├── index.html              # 单页入口
├── .nojekyll               # GitHub Pages 跳过 Jekyll 处理
└── assets/
    ├── css/style.css       # 全站样式（纸本 / 夜间两套变量）
    ├── js/
    │   ├── data.js         # 机器生成：六期全量片单
    │   ├── features.js     # 人工编辑层：每日特集池与手写评语
    │   └── app.js          # 交互逻辑
    ├── covers/             # 各作品官方视觉图（600×750，393 张）
    └── thumbs/             # 200px 宽缩略图（小尺寸场景专用）
└── tools/                  # 数据管线与 QA 脚本
```

## 本地运行

纯静态、无构建依赖。直接双击 `index.html` 即可；若需本地服务器：

```bash
python -m http.server 8080
# 或
npx serve .
```

## 数据管线（tools/）

```bash
# 1. 抓取并解析季度新番一览（長門番堂 yuc.wiki）
node tools/parse.js
# 2. 合并为 data.js（含全量片单与编辑推荐）
node tools/build-data.js
# 3. 下载各作品官方视觉图到 assets/covers/
node tools/download.js
# 4. 解析放送星期与时段，写入 dow / slot 字段
node tools/update-schedule.js
# 5. 生成 200px 缩略图到 assets/thumbs/（需 sharp）
node tools/make-thumbs.js
# 视觉 QA：无头浏览器截图（需 playwright，使用系统 Edge）
node tools/shots.js
```

> 下个季度更新只需抓取新页面并重跑第 1–5 步；`features.js` 为手写内容，不会被脚本覆盖。

## 编辑层：features.js

每日特集池与评语集中在此文件，按季度分组：

```js
"2026-autumn": [
  { match: "药屋少女", blurb: "猫猫的推理从后宫走进了朝堂……" }
]
```

- `match` 为标题片段，需在当期片单中**唯一命中**；
- `blurb` 同时用于封面故事、特集评语与详情弹窗，并决定该作是否带 ★（本站的「推荐」＝上得了封面的作品）；
- 特集按日期每日轮换：已开播者按放送日序上位，未开播者顺延，作品在开播当日自动进入轮换。

## 设计说明

- **纸本印刷语言**：和纸底色 + 墨色文字，拉丁小字用 EB Garamond，点线引导（目次 / 规格表 / 过刊索引），图版以纸边装裱并附图注。
- **号色**：每期一色——冬之深蓝、春之玫红、夏之青绿、秋之赭黄。颜色**只用于标记**（目次编号、图版标签、激活筛选、时刻表的「今日」栏），不作装饰。
- **减法原则**：不做意象图标、不做漂浮动效、不为同一件事写两遍。页面上只剩排版、图版与数据。
